## 3. ★ ダンスをどう入れるか（BCルーム発注ダンスの活かし方）

### 大前提：ダンスをフル作画でやると即死します

8秒のダンスをフル作画（8fps＝64枚）すると **64枚 × 6,250円 = 40万円（＝予算の40%）**。8秒で予算の4割です。

| 実現手段 | コスト | 判定 |
|---|---|---|
| フル作画 | 8秒で40万円 | ❌ 予算破壊 |
| ロトスコープ（実写ダンス撮影→トレス） | 撮影は安いが**枚数は同じ**＝トレス費が同額 | ❌ 意味なし |
| 3DCG＋トゥーンシェード＋mocap | 3Dアニメーション300万円〜／mocap料金は要問合せ | ❌ 予算外 |
| **Live2D／カットアウトのループ** | 一括10〜15万＋モーション5,000〜10,000円/種 | ✅ **唯一の現実解** |

### ⚠️ ABテストのタイミング問題（重要）

いただいた運用計画では「**ABテストで勝ち残った3ダンスで追撃**」とあります。しかし：

- **実写MV撮影は9/9〜9/11**（ボカロMV公開9/18より前）
- **ABテスト結果が出るのはSW明け（9/24〜）**

つまり**実写MVの撮影時点で「勝ったダンス」は分かりません。**

→ **解決策**: 実写MV撮影日（9/11・白ホリ）に、**候補3ダンスすべての引用カット（各2〜3秒）を撮っておく。** 編集は9/24〜29なので、**ABテストの結果を見てから編集で選べます。** 追加撮影コストはほぼゼロ（同一セット・同一衣装で3テイク回すだけ）。

## 5. 🚨 オケ配布とピアプロ — 落とし穴があります

### 5-1. ピアプロ単独配布は「配ったのに誰も使わない」で終わります

piapro の投稿作品は、**全作品共通で非営利限定**です（規約実確認）。

> すべての作品に共通の条件です。ピアプロ投稿作品を、**お金をとって使ったり会社の宣伝などに使ったりすることはできません。**

**投稿者側が「これを使った歌ってみたで収益化していい」と許諾を出すことが、ライセンス枠内では構造的にできません。** ボカロ／歌ってみた文化圏では「**収益化できるオケ**」であることがUGC参加の実質的な必須条件です（重音テト公式Q&Aでも「個人であればYouTube広告・ニコニコ創作奨励プログラムはOK」とされており、歌い手側は収益化を前提に動いています）。

### 5-2. ✅ 推奨：二段構えのハイブリッド配布

```
【A】ピアプロに投稿  ── 発見性・ボカロ文化圏での正統性・創作ツリーでの紐付け
   ・ピアプロ会員のコア歌い手層にリーチ
   ・ライセンスは piapro 標準（非営利）
   ・オリジナルライセンス欄に「詳細条件は公式サイト参照」と記載し【B】へ誘導

【B】公式サイト / BOOTH で本命配布  ── 条件を自分で決められる
   ・独自の「zurui 二次創作ガイドライン」を日本語＋英語で掲示
   ・「YouTube/ニコニコでの広告収益化OK」を明記 ← これが歌い手を動かす
   ・海外リスナーはピアプロ会員登録のハードルが高いため、【B】が海外向けの主導線
```

**技術メモ**: ピアプロは1投稿に**関連ファイルを最大3つ**添付できます（実物確認）。「2mix off vocal」「ドラムのみ」「ドラムなし」の3ファイルを1投稿で同梱している例あり。→ **フルオケ・キー変更用・ドラム抜きを1投稿でまとめて出せます。**

### 5-3. ⚠️ Content ID の罠

配信ディストリビューターにContent IDを登録すると、**配布したオケを使った歌ってみた動画に自動で著作権申し立てが飛びます。** 「オケを配ったのに、使った人が収益化できない／動画がブロックされる」という最悪の事故になります。

| 案 | 内容 | 判定 |
|---|---|---|
| A | オケをContent IDに登録しない | ✅ |
| **B** | **登録するが、配布オケは別ミックスにしてフィンガープリントをずらす** | ✅ **推奨**（公式MVは保護しつつUGCは自由。追加ミックス工数0.5人日） |
| C | そのまま登録 | ❌ 事故る |
