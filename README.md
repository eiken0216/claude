# パーソナルデータ ツール集

Claude Code の**スキル**として実装された、自分のデータを集めて整理するための
ツール集です。現在は次の2つがあります。

| スキル | やること |
|---|---|
| [`/notes-import`](#iphone-メモ-取り込み-notes-import) | iPhoneのメモアプリの**全メモ**をリポジトリに取り込んで整理・索引化 |
| [`/tiktok-report`](#tiktok-アナリティクス-レポート-tiktok-report) | TikTokアカウントの指標・コメントを収集してレポート化 |

---

## iPhone メモ 取り込み (`/notes-import`)

iPhoneのメモアプリ（Appleのメモ）にある**すべてのメモ**を読み込み、
リポジトリ内に整理されたMarkdownとして保存します。

- `notes/md/<フォルダ名>/<タイトル>.md` — メモ1件ずつ（作成日・更新日付き）
- `notes/INDEX.md` — フォルダごとの一覧・索引

AppleのメモはiCloudに保存されていて外部から直接読むAPIが無いため、
**iPhone側で一度だけショートカットを作り、実行するたびにGoogle Driveへ
全メモが書き出される**仕組みにしています。書き出したあとはClaudeに
「メモを取り込んで」と言うだけです。

### iPhone 側の準備（初回のみ・10分ほど）

#### STEP 0. 事前準備

1. App Storeから **Google Drive** アプリを入れて、Googleアカウントでログイン。
2. Google Driveアプリで新しいフォルダ **`iPhoneメモ`** を作る
   （右下「＋」→「フォルダ」）。
3. iPhone標準の「**ファイル**」Appを開き、下の「ブラウズ」→ 右上「⋯」→
   「サイドバーを編集」で **Google Drive をON** にする
   （すでに一覧に出ていればこの操作は不要）。

#### STEP 1. ショートカットを作る

Apple標準の「**ショートカット**」Appを開き（無ければApp Storeで入手）、
右上の「＋」で新規作成。「アクションを追加」から次の4つを順に並べます。

1. 検索欄に「**メモを検索**」と入力して追加。
   - フィルタは**何も設定しない**（＝全メモが対象）。
   - 「表示を増やす」を開き、「**制限**」のスイッチが**OFF**なのを確認
     （ONだと件数が絞られてしまう）。
2. 検索欄に「**各項目を繰り返す**」と入力して追加。
   - 「メモ」が自動で繰り返し対象になります。
3. 検索欄に「**テキスト**」と入力して追加し、
   **「各項目を繰り返す」と「繰り返しの終了」の間**にドラッグして入れる。
   テキスト欄に次を入力します（`［...］`は変数）:

   ```
   ===NOTE===
   TITLE: ［繰り返し項目 › 名前］
   FOLDER: ［繰り返し項目 › フォルダ］
   CREATED: ［繰り返し項目 › 作成日］
   MODIFIED: ［繰り返し項目 › 変更日］
   ---
   ［繰り返し項目］
   ```

   変数の入れ方: キーボードの上に出る候補バーから青い「**繰り返し項目**」を
   タップして挿入 → 挿入された青いトークンをもう一度タップ → 出てくる
   パネルで「名前」「フォルダ」「作成日」「変更日」を選ぶ。
   本文の行（最後の行）は「繰り返し項目」を**そのまま**（プロパティを
   選ばずに）置けばOK。
   ※どうしても難しければ TITLE 行と本文だけでも動きます
   （フォルダ・日付が索引に出なくなるだけ）。
4. 検索欄に「**ファイルを保存**」と入力して追加（**繰り返しの外**＝一番下）。
   - 入力が「**繰り返しの結果**」になっていることを確認
     （違う場合は青いトークンをタップして選び直す）。
   - 「**保存先を尋ねる**」は **ONのまま**にする（実行時にGoogle Driveを
     選べるのはこのモードだけ）。

最後に上部の名前を「メモ全部書き出し」などに変えて「完了」。

#### STEP 2. 実行する（毎回これだけ）

1. ショートカットの ▶ をタップ。
   - 初回は「メモへのアクセスを許可」と聞かれるので「**常に許可**」。
   - メモが多いと**数分かかります**。画面はつけたまま待つ。
2. 保存先の画面が出たら: 「ブラウズ」→ **Google Drive** → **iPhoneメモ**
   フォルダを開く → 上部のファイル名を **`notes-export.txt`** にして「保存」。
   - 2回目以降は「既に存在します」と聞かれるので「**置き換える**」。
3. Claudeに「**メモを取り込んで**」と言う。

#### うまくいかないとき

- **候補バーに「繰り返し項目」が出ない** → テキスト欄を長押しして
  「変数を選択」から選ぶ。または、テキストアクションが繰り返しの
  「中」に入っているか確認（外にあると出ません）。
- **保存先にGoogle Driveが出ない** → STEP 0-3 のサイドバー編集を実施。
  それでも出ない場合はGoogle Driveアプリに一度ログインし直す。
- **実行が途中で止まる/失敗する** → メモ件数が非常に多い場合に起きます。
  「メモを検索」の「制限」をONにして500件などに区切り、
  ファイル名を `notes-export-1.txt`, `notes-export-2.txt` と分けて
  複数回実行すればOK（スキルはフォルダ内の全ファイルを読みます）。

> 💡 Macを持っている場合の別ルート: Mac App Storeの無料アプリ
> **Exporter** で全メモをMarkdownに書き出し、そのフォルダごと
> Google Driveの `iPhoneメモ` フォルダにアップロードしてもOKです
> （スキルはバラのファイル形式にも対応しています）。

### 使い方

Claude Code 上で:

```
メモを取り込んで
```

または明示的に:

```
/notes-import
```

Claudeが次を自動で行います:

1. Google Drive の `iPhoneメモ` フォルダから書き出しファイルをダウンロード
2. 全メモをパースして `notes/md/` に整理（フォルダ構成を再現）、
   `notes/INDEX.md` を再生成
3. コミットして、件数・フォルダ内訳・気づいたテーマをチャットで報告

### 制限・注意

- **ロック付きメモ**（パスワード/Face IDで保護したメモ）はショートカットから
  読めないため取り込まれません。
- 写真・スケッチ・スキャンなどの**添付ファイルは対象外**（テキストのみ）。
- 取り込みは毎回**全量の入れ替え**です。iPhone側で削除したメモは、次回の
  取り込みでリポジトリからも消えます（Git履歴には残ります）。
- メモの中身は個人データです。このリポジトリ内に留め、外部への
  再アップロードはしない運用にしています。

## TikTok アナリティクス レポート (`/tiktok-report`)

特定の TikTok アカウントを定期的にチェックし、動画ごとの指標（再生数・いいね・
コメント・シェア・**保存数**）と、集まっているコメントを収集して、
**リポジトリ内のデータ**と**見やすい Google スプレッドシート**にレポートします。

### 使い方

```
@tiktok のレポートを出して
```

または明示的にスキルを呼ぶ場合:

```
/tiktok-report tiktok
```

Claude が次を自動で行います:

1. Playwright で対象アカウントをクロール（再生数・いいね・コメント・シェア・保存数 + 上位コメント）
2. `reports/<handle>/` にデータを書き出し
   - `metrics.csv` — 動画ごとの指標
   - `comments.csv` — 上位コメント
   - `account_history.csv` — 実行ごとに 1 行追記される時系列データ
   - `<日付>.md` — 前回比のトレンド付き 読みやすいレポート
   - `raw/<日付>.json` — 生データ
3. `metrics.csv` / `comments.csv` を **Google スプレッドシート**としてアップロード（リンクを共有）
4. チャットに要約（アカウントの傾向・トップ動画・注目コメント・シート リンク）

### 前提・注意

- **ネットワーク:** `tiktok.com` への通信が必要です。ネットワークポリシーで
  TikTok がブロックされている環境では取得できません（その場合はブロックされて
  いない環境で実行してください）。
- **bot 対策:** TikTok は自動アクセスを制限します。取得に失敗する・件数が少ない
  場合は再実行してください。ログイン済みブラウザの Cookie 文字列を環境変数
  `TIKTOK_COOKIE` に設定すると成功率が上がります。
- **手動実行:** 現状は手動実行のスキルです。毎日の自動実行にしたい場合は、
  同じコマンドを定期実行トリガー（scheduled trigger）に組み込めます。ご希望が
  あれば設定します。

## 構成

```
.claude/skills/
├── notes-import/
│   ├── SKILL.md              # Claude 向けの実行手順
│   └── scripts/
│       └── organize.mjs      # 書き出しファイル → Markdown整理 + 索引生成
└── tiktok-report/
    ├── SKILL.md              # Claude 向けの実行手順
    ├── package.json          # playwright 依存
    └── scripts/
        ├── scrape.mjs        # TikTok クローラ（Playwright）
        └── build_report.mjs  # 生データ → CSV / Markdown / 時系列

notes/                        # メモの取り込み先（INDEX.md + md/<フォルダ>/）
reports/                      # TikTokレポートの生成物（実行ごとに蓄積）
```

詳細は各スキルの `SKILL.md` を参照してください。
