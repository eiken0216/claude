### 2-2. 「海外先行バズ」構造が意味すること（A&R提案上の武器）

このプロファイルが事実なら、UNAの価値は「日本人インフルエンサー」ではなく **「海外の音源トレンドに日本から最速で乗り、海外ユーザーの発見面に載る導線を持っている」** 点にあります。

- 通常の日本人アーティストの海外展開は「国内ヒット → 海外へ」の順で、TikTokの推薦アルゴリズム上は不利
- UNAは逆で、**最初から海外の "For You" に載る**。ここに**オリジナル音源**を置ければ、楽曲側が海外チャートに直接刺さる
- つまり **「UNAが踊る＝海外に音源が配られる」** という、日本の現場では極めて希少な構造

→ 作家への営業でも、UNAへの再アプローチでも、この一点を口説き文句の中心に据えるのが最も効きます。

### 2-3. 未取得情報と次アクション

本セッションではTikTok/Instagramへの直接アクセスがブロックされ、以下は取得できていません。

- 実際のフォロワー数・再生数・**視聴者の国別内訳**
- 本人が公言しているリスペクトアーティストの一次ソース（動画・ストーリーズ）
- 使用楽曲の傾向（どの音源で伸びているか）

**次アクション（推奨）**: 本リポジトリに実装済みの `/tiktok-report` スキル（Playwrightスクレイパー）でUNAのアカウントを実測してください。ハンドルさえ確定すれば、動画ごとの再生/いいね/保存/コメントと上位コメント（＝海外比率の推定材料）が取れます。

```
/tiktok-report likekyuuna_s
```

これで **「保存率が高い＝音源として使われる素質」** と **「コメント欄の言語比率＝海外リーチの実数」** が資料化でき、そのまま作家への提案書に転用できます。

## 3. 音楽的ターゲットの定義

UNAが好きだと公言している3方向を分解すると、狙うべき音像が明確になります。

| リファレンス | 音楽的特徴 | UNA楽曲への示唆 |
|---|---|---|
| **keshi** | ローファイ／オルタナR&B。ギター基調、抑制されたボーカル、余白の多いミックス | 楽曲の「情感」「質感」の担当。歌い上げない、囁くようなトップライン |
| **ENHYPEN** | ダークで硬質なダンスR&B／トラップ。低域が太く、振付前提のリズム設計 | 「踊れる」骨格の担当。BPM 90-110 のハーフタイム／2ステップ |
| **&TEAM** | 上記の日本語版。日本語詞の乗せ方・エモーショナルなメロが確立されている | 日本語で成立させる方法論。実際に日本在住作家が多数クレジットされている |

### 狙うべき最大公約数

> **BPM 90〜110 のオルタナR&B。ギターまたはローファイ鍵盤のループ + トラップ／2ステップのドラム。サビは歌い上げず、フックはダンスの "キメ" に同期した短いリフレイン。TikTokの15秒に収まる構成。**

この仕様を満たせる作家＝本リストの選定基準にしています。

## 4. 【重要】keshi 制作陣は日本からアプローチ不可能

`keshimusic.com` の公式クレジットを全曲確認しました（アルバム『Requiem』）。中核メンバーは以下の通りで、**全員が米国拠点、日本の窓口なし**です。

| 名前 | 役割 | 拠点 |
|---|---|---|
| Elie Rizk | 共同プロデュース／共作（ほぼ全曲） | 米国（ボルチモア出身） |
| Imad Royal | 共同プロデュース／共作（ほぼ全曲） | 米国 |
| Patrick "j.Que" Smith | 作詞（ほぼ全曲） | 米国 |
| Malay | プロデュース（"AMEN"） | 米国 |
| Jacob Ray | プロデュース／共作 | 米国 |
| Connor & Riley McDonough | プロデュース／共作（"TEXAS"） | 米国 |
| Julia Michaels | 共作（"NIGHT"） | 米国 |

**結論**: このラインは、英語でのUSパブリッシャー経由交渉が必須。手塚様の英語不可という制約下では現実的ではありません。

**代替設計**: 「keshi的な質感」は、本リストの **カテゴリD（日本のR&B×ダンス最前線）** で十分に再現可能です。UNAへの提案では「keshiの本人チームを取ってきた」ではなく、**「keshiの世界観 × ENHYPEN/&TEAMの踊れる骨格を、日本語で成立させられる作家」** という立て付けにするのが正解です。

## 5. アプローチ設計（作家先行戦略の具体手順）

手塚様のプラン（作家を先に押さえてUNAに持っていく）は妥当です。ただし順序を1段だけ工夫すると成功率が上がります。

### Phase 0 — 社内リソースの確認（最優先・コストゼロ）

作家に外部から当たる前に、**ソニーミュージック社内で完結する導線**を先に潰してください。

1. **Sony Music Publishing (Japan)** の作家ロスターに該当作家がいないか照会（`smpj.jp/songwriters/`）
2. **Yaffle（小島裕規）** — 2025年6月にソニーミュージックへ移籍。藤井風のプロデューサーで、オルタナR&B × 海外実績という点でUNA案件に極めて近い。**社内ルートで話が通る可能性がある最有力候補**
3. 社内のK-POP／グローバル担当A&Rが、HYBE LABELS JAPAN や各作家事務所と既存の取引があるか確認

> 「ソニーミュージックがいるから繋がった」という手塚様の狙いを最も強く演出できるのが、この社内ルートです。個人DMより圧倒的に説得力が出ます。

### Phase 1 — 作家事務所への正規オファー（本命）

個人DMより、**事務所のA&R窓口に法人として投げる**ほうが返信率・スピードともに高いです。理由は、作家個人のDMは基本的に埋もれる／マネージャーが管理していることが多いため。

推奨する打診順（詳細は `03_contact_windows.md`）:

1. **MUSIC FOR MUSIC**（岡嶋かな多・源田爽馬・Naoki Itai・MEG が同一事務所）— 1社で複数の本命を押さえられる
2. **Soundgraphics Inc.**（&TEAM作家陣の日本語窓口。A&R専用フォームあり）
3. **tinyvoice production**（UTA・SUNNY BOY）
4. **obelisk inc.**（Lauren Kaori）
5. **STARBASE INC.**（Matt Cab・MATZ）

### Phase 2 — 個人への直接コンタクト（Phase 1 と並行可）

フリーランス化している作家（岡嶋かな多・ELVYN 等）は、公式SNSからの直接打診が正規ルートになります。

### Phase 3 — UNAへの再アプローチ

作家から「話は聞く」レベルの感触が取れた時点で、UNAに以下の構成で持っていきます。

> 「自分で作るのももちろんアリだと思う。ただ、**〇〇さん（＝ENHYPEN/&TEAMを書いている作家）が、UNAくんのために一曲書いてみたいと言っている**。この人と一緒にやる機会は、個人でDMを送っても普通は成立しない。ソニーミュージックが間に入るから成立する話。**1曲だけ、試しにやってみませんか**」

**「自作を否定しない」ことが最重要**です。UNAの「自分でやったほうがお金回りもいい」という判断は正しく、これを論破しようとすると関係が切れます。**「自作は続けたうえで、1曲だけ別レイヤーの実験をする」**という提案にすれば、断る理由がなくなります。

### 5-1. ショット契約という座組みの補足

- 自作路線を残したままなので、**専属ではなく1曲単位の原盤契約**という設計はUNA側の心理的ハードルが低い
- 印税面の不安に対しては、**作家印税と原盤印税の内訳を最初に開示**するのが有効。「自分でやったほうが儲かる」の中身は多くの場合、単に「取り分が見えないことへの不安」です
- 海外配信・海外プレイリスト・海外シンクの取り扱いは、個人では実務的に困難な領域。**ここがレーベルを噛ませる最大の実利**であり、UNAの海外リーチと直結する説得材料になります

## 6. 作家への営業トークの骨子（テンプレート）

事務所フォーム／DMいずれでも使える骨子です。**英語不要の相手を選定してあるので、日本語のままで問題ありません。**

```
件名: 【楽曲制作のご相談】TikTok経由で海外リーチを持つ日本人ダンサーのオリジナル楽曲について

〇〇様

突然のご連絡失礼いたします。株式会社ソニー・ミュージック〇〇の手塚と申します。

現在、日本人ながらTikTokで海外ユーザーに先行してリーチしている
ダンスクリエイター「UNA」のオリジナル楽曲制作を企画しております。

・海外の音源トレンドに日本から最速で乗る導線を持ち、海外の発見面に載る
・国内ヒット → 海外、という通常経路ではなく、最初から海外に届く構造
・（実数：フォロワー〇万／海外視聴比率〇%／平均保存率〇%）

本人がリスペクトを公言しているのが keshi、ENHYPEN、&TEAM で、
〇〇様の手がけられた「（楽曲名）」は、まさに本人が目指す方向性そのものです。

想定は BPM 90〜110 のオルタナR&B、ダンスが成立するリズム設計、
TikTok前提のフック構成、日本語詞（一部英語可）です。

つきましては、まず1曲、書いていただくことは可能でしょうか。
条件面・スケジュールも含め、一度お打ち合わせのお時間をいただけますと幸いです。

（署名）
```

**ポイント**
- 冒頭で「ソニーミュージック」を名乗る（これが手塚様の最大の武器）
- 作家の**具体的な既存曲名**を必ず入れる（テンプレ営業に見えなくなる）
- **数字を入れる**（`/tiktok-report` の実測値をここに差し込む）
- 「1曲」と限定する（作家側のコミット判断が軽くなる）

| **DM開放状況** | ログインなしでは「DM欄が開いているか」は技術的に確認不可 | 本リストでは**公式アカウントの特定まで**を行い、実際の開放状況は手塚様側でご確認ください（各行に確認欄あり） |
