## 3行サマリー

1. **keshi の制作陣（Elie Rizk / Imad Royal / j.Que Smith / Malay 他）は全員US拠点で、日本からの直アプローチは非現実的。** 代替として「keshi的な質感 × ダンス」を書ける日本在住作家に振り替える設計にした。
2. **ENHYPEN / &TEAM 側は日本在住作家が実際に多数クレジットされている**（源田爽馬・UTA・SUNNY BOY・Lauren Kaori・YUUKI SANO 等）。ここが最短ルート。
3. **海外トップ作家（Andreas Öberg / Erik Lidbom / ARTiffect 等）も、東京の Soundgraphics Inc. が日本語窓口を持っている。** 英語不要で "K-POPのヒット作家" に到達できる。
