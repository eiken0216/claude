## 判定方法（再現可能）

1. **母集団づくり** — YouTube を日本語・英語に加えてインドネシア語 / タイ語 / タガログ語 /
   スペイン語 / ポルトガル語 / 韓国語 / ベトナム語 / 中国語 / ロシア語で検索。
   「海外の人が実際に辿り着ける経路」から掘ることで、国内検索では出ないchを拾う。
   → **1,163チャンネル**を収集。
2. **海外コメント比率の実測** — 各チャンネルの上位動画のコメントを実際に取得し、
   文字種（かな / ハングル / タイ / キリル / アラビア / デーヴァナーガリー / 漢字のみ / ラテン）で
   言語判定。`海外% = (日本語以外) / (判定できた総数)`。
3. **TikTok** — プロフィール統計・動画統計・コメントを取得。TikTok は API が
   `comment_language` を返すので、より精度の高い言語分布が取れる。
4. **本人性・独立性の判定** — チャンネル名/概要のかな有無、概要文の言語、
   レーベル・事務所・株式会社・マネジメント表記の有無で足切り。

## 次にやると精度が上がること

- **コメント本文の感情・国別分解**：現状は言語＝国の代理指標。国コードまでは取れていない。
- **時系列**：`account_history` を取って「海外比率が上がり続けているか」を見る。楽音型の本質は
  比率そのものより **上がり方**。
- **所属の確定**：概要文のヒューリスティックなので、有力候補は個別に裏取りが必要
  （特に tomokoofficial の国籍、ハク。/ Vivanz Eden の流通形態）。
- **母集団拡大**：TikTok は検索がログイン必須で、いまはYouTube経由と外部リストからの
  逆引きで候補を作っている。`TIKTOK_COOKIE` があれば検索から直接掘れて桁が変わる。
