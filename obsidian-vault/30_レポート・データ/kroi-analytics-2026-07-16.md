# Kroi アーティスト分析レポート(興行分析つき)

- **対象**: Kroi(クロイ)— 5人組ミクスチャーバンド
- **作成日**: 2026-07-16
- **データソース**: Spotify 公式ページ / YouTube 公式チャンネル / Kroi 公式サイト(kroi.net, special.kroi.net)/ 音楽ナタリー / Billboard JAPAN / e+ ほか(末尾の出典参照)

---

## TL;DR

- **興行規模が1年で一段階拡大**: 日本武道館(2024.1、ソールドアウト)→ ぴあアリーナMM(2025.2)→ **初アリーナツアー**(2026.1、大阪城ホール+代々木第一体育館、総キャパ約2.9万人)と、ワンマンの器を毎年更新。
- **2026年は「拡大」と「深化」の二段構え**: 1月にアリーナ、夏〜秋は敢えて Zepp 規模に戻して対バンツアー「JUNGLE」(レキシ / iri / KIRINJI / スカパラ)を開催。フェスも FUJI ROCK・ROCK IN JAPAN・METROCK と主要どころを網羅。
- **音源はシングル戦略に移行**: 2024年の3rd AL『Unspoiled』以降はシングル連打(Method / HAZE / Kinetic feat. INCOGNITO / All in)。UKジャズファンクの重鎮 INCOGNITO とのコラボは音楽性の「本流接続」を示す動き。
- **ストリーミング/SNS は中堅上位で安定**: Spotify 月間リスナー約21.9万・YouTube 登録33.2万。動員力(アリーナ完売クラス)に対してストリーミング数値は控えめで、「ライブが強いバンド」型のファン構造。

### 4.4 興行面の考察

1. **年間動員キャパの急拡大**: ワンマン系のみで 2025年 約2.9万人(アリーナMM+アコ+ホールツアー)→ 2026年 約5.2万人(アリーナツアー+JUNGLE)と、**ほぼ倍増**のペース。
2. **「上げて、戻す」戦略**: アリーナ達成直後に Zepp 規模の対バンツアーを組むのは、(a) ライブハウスでの熱量維持、(b) 対バン相手(レキシ/iri/KIRINJI/スカパラ=ファンク・グルーヴ文脈の先達)からの新規ファン流入、の両取り。INCOGNITO コラボと同じ「本流と接続する」ベクトルが興行にも一貫している。
3. **収益の多層化**: チケット(¥7,000〜9,000)に加え、U-NEXT 配信・ライブ映像商品・会場イベント(物販/試飲会/CD抽選)・FC 限定公演と、興行1本あたりの収益源を増やしている。
4. **リスク/注目点**: アリーナ2公演の実動員・完売状況は非公表。JUNGLE は一般発売中のため、完売速度が現在の動員力を測る次の指標になる。次のマイルストーンは「アリーナツアーの複数都市化」または「スタジアム/野外ワンマン」。
