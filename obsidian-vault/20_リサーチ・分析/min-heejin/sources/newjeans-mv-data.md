## 観察メモ

1. **Producerクレジットの一元性**: 全MVの筆頭クレジットが「Producer: MIN HEE JIN」。MV監督は曲ごとに複数名(Heewon Shin / Dongle Shin / Wooseok Shin / Youngeum Lee / Jakyoung Kim)を使い分けており、本人がインタビューで語った「上手い奴には触らない。特技を毀損せず道を開けるのがディレクター」「少数の、自分の意図を分かる人とばかり仕事をする傾向」の実装形が確認できる。
2. **Performance版がメインMVを上回る現象**: OMG Performance ver.1(4.1億)、Ditto Performance(2.1億)、Hype Boy Performance ver.1(2.5億)がside A/Official本編を大きく上回る。TikTok/ショート動画時代の「踊ってみた」導線を意識したマルチバージョン設計の成果。
3. **マルチバージョン戦略**: 1曲に対し side A / side B / Performance / メンバー別(Hype Boy)と複数MVを展開し、物語派とダンス派の両方に入口を作る。「大衆が消化できる呼吸」「体験のシーケンス設計」の実例。
4. **広告の作品化**: ETA(Apple iPhone)、How Sweet(Coke Studio)、GODS(Riot Games)など、広告・タイアップを通常コンテンツと同一品質のMVとして公開し、#광고 表記込みでもファンコンテンツとして消費される設計。
