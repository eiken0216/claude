これまで Claude Code の各セッション(GitHubリポジトリ `eiken0216/claude` の全ブランチ)で
作成した Markdown 成果物 **全76件** を、Obsidian で読み込める形に集約した Vault。

## AIへの利用ガイド

- 各ノートの frontmatter に `project` / `source_branch` / `source_path` / `created` を記録している。出典を辿るときはこれを使う。
- 企画書を書くとき → `10_企画・施策` の過去企画の構成(目的→ターゲット→施策→KPI→スケジュール)を踏襲する。
- リサーチを頼まれたとき → `20_リサーチ・分析` の粒度(出典URL明記・ロングリスト+優先度・連絡窓口まで)を基準にする。
- 定型レポート・自動化 → `50_スキル・ワークフロー` の SKILL 定義をそのまま手順書として再利用できる。
- 人名・数値・連絡先は作成時点(created)のスナップショット。使う前に最新性を確認する。
