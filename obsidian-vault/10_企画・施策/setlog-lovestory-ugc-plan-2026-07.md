# 小田和正「ラブ・ストーリーは突然に」× setlog お手製ドラマ風UGC施策 設計書

作成日: 2026-07-08 ／ 調査手法: 並列ウェブリサーチ7系統（setlog仕様・Newbeans・楽曲権利/文脈・インフルエンサー・レーベル3種・全レーベル・リバイバル事例）

## 0. エグゼクティブサマリー

- **ファーストペンギン仮説は正しい。** setlogのレーベル公式活用・企業タイアップ事例は2026年7月時点で**ゼロ**（確認可能な範囲）。K-POPアイドル（SEVENTEEN・aespaカリナ）のオーガニック利用が火付け役になった段階で、音楽レーベルが「音源×setlogフォーマット」を設計した前例はない。
- **ただしsetlogにはアプリ内音源機能がない。** BGMはCapCut等の外部編集で後付けし**TikTok/リールに転載する文化**が主流。つまり本施策の露出とKPIの主戦場は「setlogで撮る → TikTokで公式音源を付けて投稿」の転載側に置く。
- **最重要の事前タスクは音源整備。** 「ラブ・ストーリーは突然に」はサブスク解禁済（2019年〜）で「2024Ver.」も配信中だが、**TikTok公式音源としての利用可否は未確認**。仕込み開始前にアリオラ／SMM経由で公式サウンドページの整備（＋CapCut商用ライブラリ登録）を完了させることが施策の前提条件。
- **投稿の「凝縮」は正解。** アルゴリズムは総再生数より**「同一音源を使う人数と多様性」を初動48時間**で評価する（Billboard Pro/Chartlex、LUMOS・NORDERの商品設計、BBBB声優リレーが実証）。ただし1日で全部出すと広告臭で自然発生UGCが萎縮するため、**「48〜72時間バースト＋2週間の波状燃料投下」のハイブリッド**を推奨。
- **推奨構造は4層×3波。** ①Newbeans初動で「型」を提示（8月前半）→ ②夏休み最終盤の週末（8/21–23推奨）にジャンル分散20〜40組の凝縮バースト → ③9月第2週にソニーアーティスト波状リレー＋公式の後追い → ④回収（チャート実績の報道化・プレイリスト・カラオケ・公認リミックス）。

## 1. ファクトベース（調査結果の要点）

### 1.1 setlog（セットログ）

| 項目 | 事実 |
|---|---|
| 運営 | New Chat Inc.（韓国発、NY/ソウル拠点の小規模スタートアップ）。iOS 2025年12月（韓国）→ 2026年4月に日本語・Android対応 |
| 形式 | 1時間ごとに通知 → **約2秒**のクリップをその場撮影（過去動画アップ不可）。1日の終わりに全クリップが自動連結され縦型ミニVlogが完成。午前4時リセット |
| 共同機能 | 招待制グループ「ログ」に**最大12人**。別々の場所にいる友達のクリップが分割画面表示され、**全員分が1本の共同Vlogに自動合成**（=「一緒にバズろう」の共謀構造そのもの） |
| 音源 | **アプリ内BGM機能なし**。環境音ON/OFFのみ。BGMはCapCut/InShot等で外付け→TikTok/リール転載が定着 |

| 火付け役 | SEVENTEEN現メンバー9人全員、aespaカリナのVlog投稿（AP通信報道） |
| 企業活用 | 広告メニューなし・企業タイアップ事例**未確認** → 先行者利益が取れる状態 |

主要出典: [Impress Watch](https://www.watch.impress.co.jp/docs/news/2116019.html) / [日経](https://www.nikkei.com/article/DGXZQOUC112O80R10C26A6000000/) / [CyberLink](https://www.cyberlink.com/blog/app-video-editing/5527/what-is-setlog-app) / [渋谷トレンドリサーチ](https://shibuya-trendresearch.jp/monthlytrendsurvey/4480/) / [AP通信（Yahoo配信）](https://malaysia.news.yahoo.com/app-made-viral-k-pops-061232294.html)

**設計への含意:**
1. setlogは「撮影・共謀装置」、TikTokは「拡散・音源装置」と役割分担して設計する
2. リアルタイム撮影限定（作り置き不可）という制約が逆に「1日かけて友達とドラマを仕込む」ドキュメンタリー性を担保する
3. 中高生中心のアプリなので、楽曲側の「親世代文脈」（1991年・280万枚級ヒット）との**二重ターゲット構造**を組み込む

### 1.2 楽曲・権利まわり

- 小田和正は**アリオラジャパン所属**（ソニー・ミュージックレーベルズ内）— 原曲と起用アーティストを同一グループ内で完結できる
- サブスクは**2019年5月解禁済み**。さらに**「ラブ・ストーリーは突然に (2024Ver.)」**が『自己ベスト-3』（2024年11月）と同時配信中
- **TikTok公式音源としての整備状況は未確認**（SME×TikTok包括契約は2019年〜、邦楽約9万曲提供済みだが小田和正楽曲の個別確認が取れず）。現状のTikTok上のUGCは**ライブ音源の当て込みが中心**＝公式サウンドページに再生が集約されていない
- 追い風: **NHK『名曲考察教室 小田和正スペシャル』（2025年12月24日放送）**で本楽曲を"令和の感覚"で考察・MV制作（鈴木保奈美サプライズ出演）。Night Tempo × ELAIZAカバー（2024年、フジ番組主題歌）。JOYSOUND小田和正内1位。2026年は**「東京ラブストーリー」放送35周年**
- Z世代ポジション: 「ダンスバズ曲」ではなく**「エモい名曲」**（KKBOX「Z世代にバズった昭和平成の名曲42選」選出。一方SimejiのZ世代バズ曲TOP10には不在）→ ダンスチャレンジではなく**ドラマ風UGC**という企画方向はデータと整合

## 2. クリエイティブ設計 —— setlogならではの「型」

setlogの良さ3点（共謀できる／手軽に作品作り／2秒フォーマット）を、楽曲の資産（イントロ「チャカチャーン」・トレンディドラマOPのモンタージュ記憶・すれ違い→出会いの物語性）に接続する。

### 型A: 「ラブストOPごっこ」（本命・模倣性最強）
東京ラブストーリー的な**90年代ドラマのOP映像を、友達との日常2秒クリップ×12カットで自作**する型。イントロのギターに合わせて場面が切り替わり、サビ頭「あの日あの時あの場所で〜」で"タイトルカード"（自分たちの名前をドラマ出演者風にクレジット）を出して落とす。
- setlogの1日ログがそのまま素材になる（=手軽に作品作り）
- 「キャスト: 全員友達」のクレジット文化が共謀・タグ付け連鎖を生む
- ※フジテレビのドラマ名・映像の直接使用は権利リスクがあるため、「90年代ドラマ風」の**様式のパロディ**に留める（タイトルロゴ模倣はNG、明朝体白文字クレジット等の「らしさ」でとどめる）

### 型B: 「1日仕込みドッキリ告白」（カップル/友達グループ向け）
友達が共謀し、setlogで**朝から告白（またはサプライズ）当日の裏側を2秒ずつ記録**。完成した1日Vlogに楽曲を乗せると「仕込み〜本番〜涙」が勝手にドラマになる。ドッキリ系カップルクリエイターの既存文法と完全互換。

### 型C: 「すれ違いモンタージュ」（2秒フォーマットの様式美）
離れた場所にいる2人（または12人）のクリップが分割画面で並ぶsetlogの仕様を使い、**「同じ街で、すれ違い続ける2人」**を演出。最後の2秒だけ同じフレームに入る。イントロ→サビの高揚と完全同期。カップル/俳優系向けの「上手い人」用フォーマット。

### 型D: 「親世代に見せてみた」（二重ターゲット装置）
完成したsetlogドラマを**親に見せるリアクション**、または「お母さんにこの曲でエモVlog作ってって頼んだら本気出してきた」型。真夜中のドアの「親に聴かせる」パターンの移植。認知の世代橋渡しとチャート回収（親世代のサブスク再生）を担う。

### ハッシュタグ設計
- メイン: **#ラブストは突然に**（楽曲略称・検索専有可能）
- フォーマットタグ: **#2秒ドラマ** ＋ **#setlogドラマ**
- 英語併記: **#LoveStoryWaTotsuzenni** （越境用。BBBBの日英二重タグ設計を踏襲）
- ドラマ名（東京ラブストーリー）はフジテレビIPのためキャンペーンタグには使わない

### Phase 0（今すぐ〜7月末）: 前提整備 ※ここが律速

2. **キャスティング発注**: メガ層は制作リードタイム3〜4週間。Wave 2に間に合わせるには**7月中旬までに主要候補へ打診開始**

5. 計測基盤: 音源ページUGC数・タグ再生数・Spotify/AppleのDaily再生・カラオケ・setlog言及数のトラッキングシート

### Wave 1（8月前半）: Newbeans初動 = 「型の提示」

- Newbeans制作・ディレクションで**2〜3組×各1〜2本**。広告臭を徹底排除しつつ、対価性がある投稿にはPR表記（タイアップラベル）を付ける
- 内容: 型A「ラブストOPごっこ」1本＋型B「1日仕込みドッキリ」1本＋型C「すれ違い」1本。**導火線枠（タイガの振り付け or ローカルカンピオーネ）をこの段階で1組併走**させ、「誰でも真似できる2秒の型」を市場に置く

### 観察期（8/10頃〜8/18）: 勝ち型の選抜

- Wave 1の保存数・コメント質・模倣発生率を比較し、**バーストに載せる型を1〜2個に絞る**（imase式テストマーケの移植）

### Wave 2（推奨 8/21(金)夜〜8/23(日)）: 凝縮バースト ※本丸

## 5. リスクと要一次確認リスト

1. **【最重要】小田和正楽曲のTikTok/Instagram公式音源可否** — 本人・事務所（ファーイーストクラブ）の意向確認を最初に。NGならプランB（2024Ver.／新規カバー／既存カバー活用）へ即分岐
2. **東京ラブストーリーIP（フジテレビ）** — ドラマ名・映像・ロゴは不使用。「90年代ドラマ風」の様式パロディに徹する。タイトルカード様式のガイドラインをクリエイティブキットに明記
3. **ステマ規制** — 全対価性投稿にPR表記。発注書面に表記義務を明記。TikTok Japan自身の炎上前例（2022年、報酬×拡散依頼×表記なし）と同じ構図を絶対に作らない
4. **setlog運営（New Chat Inc.）** — 通常利用の範囲なら承諾不要だが、アプリ名をキャンペーンタグに使う場合（#setlogドラマ）は商標面の確認を推奨。運営との公式コラボ（初のレーベル連携）を打診する価値もある（先方も事例が欲しいフェーズのはず）
5. **数値の鮮度** — 本書のフォロワー数は2025〜2026年の検索ベース概数。契約前に一次確認必須。修一朗・ばんばんざい等は増減の形跡あり
6. **setlogのトレンド寿命** — BeReal同様、急伸アプリは失速リスクあり。本設計はsetlogが失速しても**TikTok上の「#2秒ドラマ」フォーマットとして自立**する構造（ヘッジ済み）
7. **Newbeansの公開実績が確認できない点** — 株式会社NewBeans（渋谷区円山町、2024年5月設立、法人番号4011001162072）の実在は登記確認済みだが、Web上に事業実績の公開情報なし。社内与信・契約実務は営業資料と登記の照合を推奨
