## EP 全体テーマ（提案）

メンバー7名の案には、表現は違えど**同じ一本の線**が通っています。

| メンバー | テーマ | 芯 |
|---|---|---|
| ITARU | SCANDAL | 枠組みを超えて表現する |
| KENT | 自分らしさに自信／勇気をもって一歩 | ありのままの自分を貫く |
| Ray | KO（Knock Out） | 強敵と、自分の弱さを打ち倒す |
| 春空 | 交わす | 音楽で会話する |
| 冨田 | 自分自身を鼓舞する | 灰色の世界から這い上がる蒼い灯火 |
| 無記名(P9) | 妖艶・漂う | 夜の海の奥底で生き場を探す |

**共通項は「対峙して、越える」。**
前作『MOTTO』が龍宮城の**現在地**を示した EP なら、次作は**その先へ出ていく**EP。

> ### 推奨テーマ：**「SCANDAL」**（サブコピー：*その先へ、対戦よろしくお願いします*）
>
> - ITARU の原案をそのままEPタイトルに採用。ネガティブな語を反転させる構造が、
>   「枠を超える／殴り込む／越境する」という全員の芯を一語で束ねられる。
> - Ray の「KO」は M5 のユニット曲タイトルとして活かし、EP の**攻めの側**を担保。
> - 世界観のトーンは無記名(P9)案の**「夜の海」**で統一（龍宮城の看板とも直結）。
>   荒れた海を渡る＝冨田案の「這い上がる」、海の底＝「妖艶・漂う」、
>   その海の上で交わす言葉＝春空案「交わす」、と5曲すべてが同じ海の中に置ける。

※ 決定事項ではなく提案です。「KO」を EP タイトルに寄せる案（京王アリーナとのダブルミーニング）も
有効なため、アリーナ公演との紐付けを優先するなら KO 推し。→ [確認事項](#確認事項) 参照

## 5曲の役割分担マップ

```
        熱量・BPM 高
             ▲
     M2 不良/ヨーソロー ●        ● M5 KNOCK OUT (HIPHOP)
        (全体・シンガロング)         (ユニット・攻)
             │
   歌 ◀──────┼──────▶ ラップ / トラック
             │
     M3 バラード ●     ● M1 SCANDAL (ビートチェンジ)
        (全体・弾き語り可)   ※3編曲で全象限を横断
             │
        M4 R&B ●
        (ユニット・妖艶)
             ▼
        熱量・BPM 低
```

- **歌もの3曲（M1の一部・M3・M4）／ラップ主体1曲（M5）／全員もの2曲（M2・M3）**という配分。
- KENT が挙げた「BPM が低い歌える曲がほしい」「ラップ主体だと龍宮城の良さが消える」という
  懸念に対し、**ラップは M5 のユニット曲に集約**し、他4曲は歌を主役に据える設計にしています。
  同時に Ray が希望した「ゴリゴリの HIPHOP トラックでメンバー作詞」も M5 で満額実現します。
  相反して見えた2人の要望を、曲ごとの役割分担で両立させるのが今回の設計の要点です。

## 確認事項

企画を確定させるにあたり、判断が必要な点です。

1. **EP タイトル**：「SCANDAL」推し（本書の前提）か、「KO」（京王アリーナとのダブルミーニング）か。
   アリーナ公演との連動を優先するなら KO。→ 早期決定推奨（MV・衣装・ビジュアルの起点になるため）
2. **Ray『Parallel』の扱い**：本人作詞作曲・尺長め（RONDO／零零系）。今回の5曲枠には入れていません。
   ①M3 のバラード枠を Parallel に差し替える ②カップリング／配信先行として別枠 ③次作へ保留、の3択。
3. **リリース日・全体スケジュール**：上記は雛形です。確定日をいただければ実日付に落とします。
4. **ユニット分け**：M4（歌）・M5（ラップ）のメンバー選定。→ 各企画書に選定基準を記載しています。
5. **メンバーデモの反映**：KEIGO・Ray のデモ音源（Dropbox）は本環境から参照できていません。
   聴取のうえ、どの枠に当てはめるか（特に M4・M5）を別途すり合わせさせてください。
6. **M1 の尺**：3編曲構成は 4:30 を超える想定です。配信尺とライブ／MV 尺の出し分け要否。
