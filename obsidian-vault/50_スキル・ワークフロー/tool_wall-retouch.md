# wall-retouch — 背景の壁クリーンアップ

TFT 関連 SNS コンテンツのトンマナに合わせて、撮影素材の**背景の壁**を整えるツールです。
動画・静止画のどちらにも使えます。

落とせるもの:

- 壁の**色かぶり**（黄色いムラ）
- 照明による**明暗のムラ / 光の筋**
- 壁の**シミ・汚れ・コーナーの落ち込み**

**壁の色味は元のまま**にします。真っ白に飛ばすと「白抜きした感」が出るため、
目標色は壁自身の中央値カラーで、そこから数％だけ明るくする方式です
（`lift`、既定 1.06）。フラットフィールド補正は**除算**なので粒状感（グレイン）が
残り、被写体と背景でノイズ感が揃います。

被写体（肌・衣装・髪）は触りません。補正はシルエットの手前でゲインが 1.0 に
戻るようフェードするため、後れ毛や壁への接地影は残ります。

## 使い方

```bash
pip install numpy opencv-python-headless        # 必要なのはこれだけ（+ ffmpeg）

# 動画: lift=1.06、CRF=19、上限ビットレート 8600k
python3 retouch_video.py IN.mov OUT.mp4 1.06 19 8600k

# 静止画（--cmp で before/after 比較画像も出力）
python3 retouch_photo.py IN.jpg OUT.jpg --cmp
```

`lift` を `1.0` にすると明るさは元のまま、ムラだけが取れます。

## 仕組み

1. **壁マスク** — 「明るく彩度が低い」かつ「画面端から連続している」画素を壁と
   判定します。連結判定の前に一度収縮させるので、白シャツのような明るい衣装に
   マスクが漏れません。判定は 2 パスで、1 パス目のざっくりした壁色を基準に
   2 パス目は**相対的な明るさ**で判定するため、隅で暗く落ちている壁も
   きちんと壁として拾えます。
2. **フラットフィールド補正** — 壁の色を画像ピラミッドで補間して（被写体の
   裏側も埋めて）なめらかな照明フィールドを作り、それで割ります。これで
   低周波の色かぶりと明暗ムラが消えます。
3. **シミ除去** — 補正後に残った「目標色とのズレ」を壁の内側だけで低域通過
   させ、差し引きます。シミ・汚れはこのスケールで消え、それより細かい
   グレインは残ります。
4. **エッジ保護** — 2 と 3 はどちらもシルエットに近づくほど効きが弱くなるので、
   壁に落ちている自然な影はそのまま残ります。

動画では照明フィールドをフレーム間で EMA 平滑化し、さらに目標色をクリップ
全体から一度だけ測るため、背景がドリフトしたりちらついたりしません。

## 主なパラメータ（`retouch.py`）

| 名前 | 既定値 | 意味 |
| --- | --- | --- |
| `lift` | 1.06 | 壁自身の色から何倍明るくするか。1.0 で元の明るさのまま |
| `target` | 自動 | 揃える先の色。動画ではクリップ全体から測った値を使用 |
| `stain` | 1.0 | シミ除去の強さ（0 で無効） |
| `stain_sigma` | 9 px | シミとみなすぼかし半径。これより細かい粒状感は残る |
| `s0` / `s1` | 10 / 34 px | シルエットから何 px 離れたらシミ除去を効かせるか |
| `gain_hi` | 1.80 | 補正ゲインの上限。暗いコーナーもここまで持ち上げます |
| `feather` | 9 px | 壁マスクのぼかし量（ゲインのフェード幅） |

px 単位のパラメータは画像幅 946 px を基準に自動でスケールします。
