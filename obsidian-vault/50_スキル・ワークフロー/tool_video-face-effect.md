# video-face-effect — ライブ映像の顔隠しエフェクト

19秒のライブ映像(縦404x720, VFR ~23.97fps)に対して、顔がわからないように
2パターンのエフェクトを合成するパイプライン。

## 出力

- `out_A_mad.mp4` — パターンA: 顔+肌(手)を MAD 風のアニメーションエフェクトで覆う。
  白/赤/ピンクの光るスクリブル、白黒ストライプ、ネオン渦、黒抜きが
  ショットごとに切り替わる(参考: 路地裏の参考動画)。
- `out_B_hamster.mp4` — パターンB: girigiri.hamster 参考動画のハムスターイラストを
  頭部にトラッキング合成。参考動画の実際の絵をそのまま切り出したスプライトを使用し、
  質感・キャラデザを完全一致させている。3フレームごとの絵の差し替え+微ジッターで
  手描きのボイル感を再現。冒頭のギタリストにも小さいハムスターを配置。

## パイプライン

1. `track_pose.py` — YOLOv8m-pose をガンマ増感フレームに適用し全453フレームの姿勢を検出
2. `build_tracks.py` — ボーカルの頭部トラックを構築(補間+平滑化)。手首の観測も保存
3. `extract_sprites.py` — 参考動画からハムスターの絵をHSV+成分分析で切り出し(BGRA)
4. `render_mad.py` — パターンAのレンダリング(頭部楕円+手首円+歌唱時のマイク拳の手動領域)
5. `render_hamster.py` — パターンBのレンダリング(ポーズ別スプライト+ボイルアニメ+ヒゲ描画)

`common.py` は共有ヘルパー(トラック読込、手のトラック化、エッジのラフ化、
ffmpeg エンコーダ)。`tracks.json` は構築済みトラック。

入力の元動画・参考動画はセッションのアップロードファイルを参照しているため
リポジトリには含まれない。照明が青被りしていて肌色検出が効かないため、
肌領域はジオメトリ(姿勢キーポイント+手動楕円)ベースで覆っている。
