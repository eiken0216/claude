# 朝の業務ブリーフ

その日の予定を Google カレンダーから読み取り、(1) 各予定に直前リマインドを設定し、
(2) 「今日は何をすべきか」をまとめてメールで送る。

## 送信先

- **宛先:** eiken.tezuka@sonymusic.co.jp（業務用アドレス）
- **手段:** Gmail コネクタ（送信元は eiken0216@gmail.com）

## 手順

### 1. 今日の予定を取得する

`mcp__Google_Calendar__list_events` で当日（ローカルタイム＝JST）の予定を全カレンダー分取得する。
終日予定と時間指定の予定を区別すること。

### 2. 各予定に直前リマインドを設定する

ユーザーは打合せに遅れがちなので、**これがこのスキルの主目的のひとつ**。

時間指定の予定それぞれについて、`mcp__Google_Calendar__update_event` で
`reminders` を上書きし、**15分前**と**5分前**のポップアップ通知を設定する。

- すでに 15分前・5分前の両方が設定済みの予定は、API を呼ばずにスキップする。
- **自分が主催者でない予定でも、`reminders` は参加者ごとの設定なので変更してよい**
  （他の参加者には影響しない）。予定の時刻や内容そのものは絶対に変更しない。
- 終日予定にはリマインドを設定しない。
- 移動が必要そうな予定（場所が設定されていて、オンライン会議 URL がないもの）は、
  15分前ではなく **30分前と10分前**にする。

更新に失敗した予定があっても止めず、最後にまとめて報告する。

### 3. ブリーフ本文を組み立てる

以下の構成で、簡潔な日本語のプレーンテキストを書く。装飾は最小限にする。

```
おはようございます。M月D日（曜）のブリーフです。

■ 今日の予定（N件）
 10:00-11:00  週次定例 / 会議室A     ← 移動あり・9:30通知
 14:00-14:30  〇〇さん打合せ / Meet
 （予定がなければ「予定はありません」）

■ 今日やるべきこと
 - （予定から読み取れる準備事項。資料が必要そうな打合せ、
    直前に確認すべきこと、初対面の相手がいる打合せなど）

■ 注意点
 - （移動時間が厳しい連続予定、開始が早い予定、
    終業が遅くなりそうな日など。無ければこの節は省く）

■ 打刻
 出勤打刻は業務PCのログオン時に自動で行われます。
 退勤打刻のリマインドは20時、未打刻の場合は22時にメールが届きます。
```

**「今日やるべきこと」は予定から機械的に転記するのではなく、中身を読んで
準備が必要なことを推測して書く。** 例えば「提案書レビュー」という予定があれば
「提案書レビュー（14:00）— 事前に資料に目を通しておく」のように書く。
予定のタイトルだけでは何も推測できない場合は、無理に埋めずに省略する。

### 4. メールを送信する

`mcp__Gmail__create_draft` で下書きを作り、送信する。
件名: `[今日の予定] M月D日（曜）N件の打合せ`

### 5. 結果を報告する

チャットには、送信した旨とリマインドを設定した予定の件数だけを簡潔に返す。
ブリーフ本文をチャットに再掲しない。

## 注意

- **祝日**: 日本の祝日にあたる場合は、ブリーフを送らずに終了する。
  判断がつかない場合は送る（送りすぎより、送らなさすぎのほうが困る）。
- 予定が 0 件の平日でも、ブリーフ自体は送る（「予定なし」と分かることに価値がある）。
- カレンダーの取得に失敗した場合は、その旨だけを書いたメールを送る。黙って終わらない。

## 今後の拡張

ユーザーは Obsidian またはタスク管理アプリとの連携を検討中。
連携先が決まったら、「今日やるべきこと」の節にタスク一覧を統合する。
それまではカレンダー由来の情報のみで構成する。
