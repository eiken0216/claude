# wall-retouch — 背景の白壁クリーンアップ

TFT 関連 SNS コンテンツのトンマナに合わせて、撮影素材の**背景の壁**を
きれいな均一の白に整えるツールです。動画・静止画のどちらにも使えます。

落とせるもの:

- 壁の**黄色いムラ**（色かぶり）
- 照明による**明暗のムラ / 光の筋**
- 壁のシミ・ノイズ・コーナーの落ち込み

被写体（肌・衣装・髪）は触りません。補正は壁の領域だけに掛かり、シルエットの
手前でゲインが 1.0 に戻るようにフェードします。後れ毛のような細いディテールも
そのまま残ります。

## 使い方

```bash
pip install numpy opencv-python-headless        # 必要なのはこれだけ（+ ffmpeg）

python3 retouch_video.py IN.mov OUT.mp4         # 動画（音声はそのままコピー）
python3 retouch_photo.py IN.jpg OUT.jpg --cmp   # 静止画（--cmp で before/after も出力）
```

## 仕組み

1. **壁マスク** — 「明るく彩度が低い」かつ「画面端から連続している」画素を壁と
   判定します。連結判定の前に一度収縮させるので、白シャツのような明るい衣装に
   マスクが漏れません。判定は 2 パスで、1 パス目のざっくりした壁色を基準に
   2 パス目は**相対的な明るさ**で判定するため、隅で暗く落ちている壁も
   きちんと壁として拾えます。
2. **フラットフィールド補正** — 壁の色を画像ピラミッドで補間して（被写体の
   裏側も埋めて）なめらかな照明フィールドを作り、それで割ります。これで
   低周波の色かぶりと明暗ムラが消えます。ゲインは被写体の上では 1.0 に
   フェードします。
3. **ホワイトアウト** — シルエットから十分離れていて、補正後すでに白に近い
   画素だけを、フラットな白（RGB 250）にブレンドします。残ったザラつきや
   シミがここで消えます。

動画では照明フィールドをフレーム間で EMA 平滑化しているため、ちらつきません
（実測でトップセンターの背景値はフレーム間差 0.04/255 以下）。

## 主なパラメータ（`retouch.py`）

| 名前 | 既定値 | 意味 |
| --- | --- | --- |
| `TARGET` | 250,250,250 | 仕上がりの白。完全な 255 にすると切り抜き感が出るため少し下げています |
| `gain_hi` | 1.75 | 補正ゲインの上限。暗いコーナーもここまで持ち上げます |
| `d0` / `d1` | 3 / 14 px | シルエットから何 px 離れたらフラット白にし始めるか |
| `tol` | 0.10 | 白とみなす許容差。大きいほど濃い影まで飛ばします |
| `feather` | 9 px | 壁マスクのぼかし量（ゲインのフェード幅） |

px 単位のパラメータは画像幅 946 px を基準に自動でスケールします。
