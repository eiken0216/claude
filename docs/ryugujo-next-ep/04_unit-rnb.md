# M4｜ユニット曲「REPLAY（仮）」／歌メロ R&B

> **枠：** ユニット曲（歌唱ユニット）／歌メロ R&B
> **仮タイトル候補：** REPLAY ／ BLESS ／ 愛愛愛なんて
> **ポジション：** EP の陰。夜のパート。照明を落として魅せるユニット曲

---

## 1. ログライン

**「夜の海の、いちばん底。目だけで交わす会話。」**

## 2. コンセプト

メモの **「歌メロ R&B → REPLAY みたいな曲」** を軸に、
メンバー案（P9・無記名）の世界観をそのまま被せた一曲です。

> 全体的なテーマとして、今までのような元気系やパワー系ではなく
> **妖艶で漂ってる感じ**の雰囲気にしてみたい。
> 世界観としては、**夜の海の奥底で生き場を探しながらもがいてる姿を美しく見せる。**（P9・無記名）

この「夜の海の奥底」は、**EP 全体のトーンの基準**になる強いイメージです。
本曲はそれを最も純度高く体現するトラックとして位置づけます。

同時に、春空案「交わす」を**言葉を使わない交わし方**——**視線を交わす**——で受けます。
M3 が「言えなかった言葉を花に託して渡す」曲なら、
本曲は**「言葉を使わずに全部通じてしまう」**曲。EP 内で対になる設計です。

**「もがいている姿を美しく見せる」**という原案の一行が本曲の演出方針そのものです。
苦しさを苦しく描かず、色気に変換する。ここが M5（同じ苦しさを攻撃性に変換する曲）との対比になります。

## 3. サウンド設計

| 項目 | 内容 |
|---|---|
| BPM | 92（ハーフタイム感。手拍子は入らない速度） |
| キー | マイナー。7th・9th・テンションを常用し、明確な解決を避ける |
| 尺 | 3:30〜3:50 |

### 音色設計

- **R&B / ネオソウル。** ローズピアノ、ミュートしたクリーンギター、丸いエレキベース。
- **ドラムは生寄り。** ゴーストノートの多いスネア、少しヨレたグルーヴ。打ち込み然とさせない。
- **ボーカルこそが主役の音色。** ハーモニー3〜4声を常時敷き、ウィスパー／フェイクを多用。
- **水の質感。** リバーブは深く、ディレイは長く。輪郭をわざとぼかす（＝海の底）。
- **低音は太く、しかし静かに。** サブベースで沈み込む感じを出す。
- **サビでも音数を増やさない。** 盛り上げず、**濃くする**。

### 展開イメージ

```
0:00  Intro   コードとブレスだけ。水中のような残響
0:12  A1      ウィスパー気味のソロ。譜割りは細かく、後ろノリで
0:40  B1      ハーモニーが増える。ここで色気が立ち上がる
0:56  Sabi 1  音数を増やさない。声の重なりだけで密度を上げる
1:24  A2      ラップ寄りの語り（歌の延長としての語り。硬いラップにしない）
1:50  B2 → Sabi 2
2:30  Bridge  **一番低い場所。** ほぼ無伴奏、フェイクの応酬
2:50  Last    最も濃いハーモニー → 突然、音が全部消えて終わる
```

**設計意図：** 本曲だけは**カタルシスを与えない**。
最後まで解決させず、ぷつりと切る。EP の中に1曲、
**聴き終えたあとに引っかかりが残る曲**を置くための設計です。

## 5. 歌詞テーマ

**「言葉を使わずに、全部通じている。」**

- 舞台は**夜の海の底**。あるいは夜の部屋。どちらとも取れる曖昧さを残す。
- **視線・呼吸・体温・沈黙**で会話が成立している状態を書く。台詞を書かない。
- 春空案「交わす」を**「視線を交わす」**として直接使用。サビのキーワード候補。
- 「もがいている」ことを、苦しさとしてではなく**美しさ**として描く（P9 原案の指示どおり）。
  溺れる／沈む／息が続かない——といった語を、ネガティブに着地させない。
- **一人称・二人称を明示しすぎない。** 誰と誰の話かを確定させないほうが色気が出る。
- **避けたい表現：** 直接的な性的描写。あくまで匂わせと余白で作る。
- **避けたい表現：** 説明的なサビ。この曲は「何を言っているか」より「どう聞こえるか」を優先。

**発注時の必須伝達事項**

1. **サビで音数を増やさない。** 盛り上げるのではなく濃くする
2. ハーモニー前提で書いてほしい（3〜4声を常時想定）
3. BPM 95 以下、ハーフタイムのグルーヴ
4. **解決しないまま終わる**エンディング
5. 譜割りは細かく、後ろノリ。日本語の子音の立ち方まで意識した歌メロ

## 7. ユニット構成・歌割設計

### メンバー選定基準（3〜4名）

本曲は**技術ではなく声質と相性**で選ぶべきユニットです。

1. **ハーモニーが組める**こと（ピッチの安定と、他人の声を聴いて合わせられること）
2. **ウィスパー／ファルセットで表現できる**こと（本曲は地声で押す曲ではない）
3. **声質のコントラスト**があること。似た声を3人並べるより、
   低く太い声・中域の芯・高く細い声が1人ずついる編成が理想
4. 譜割りの細かい後ろノリを処理できるリズム感

→ 具体的な人選は歌唱チェック（デモへの仮歌テスト）を経て決定することを推奨します。

### 歌割

| パート | 設計 |
|---|---|
| A メロ | ソロ。**一番低い声から**入る |
| B メロ | 2声のハーモニー。上下を入れ替えながら |
| サビ | 3〜4声のハーモニー。**主旋律を誰か1人に固定しない**（曲中で主旋律が移動する） |
| A2 の語り | 歌の延長としての語り。硬いラップにはしない |
| ブリッジ | フェイクの応酬。**アドリブ枠**を確保し、レコーディング当日に本人たちに投げる |
| ラスト | 最も濃い和音。全員 |

- **アドリブ／フェイクは譜面で縛らない。** ここが本曲の個性の出どころになります。
- ソロの「歌唱力」ではなく**声の質感**で聴かせる曲なので、
  歌割は「上手い順」ではなく「その質感が必要な場所」で決める。

## 8. ライブでの機能

- **本編中盤、最も照明を落とすパート。** 前後の全体曲との落差で機能します。
- 椅子・階段・センターステージなど、**動かない演出**。振付は最小限。
- ユニット曲のため、**残りのメンバーの衣装替え時間としても機能**します（進行上の実利）。
- P9 原案の「ライブで一気に世界観を持ってこれる楽曲」という要望に直接応える枠です。

## 9. ビジュアル／MV

- **鍵となる画：** 水中。青と黒。光は上から一筋だけ。
- 実際の水中撮影、または水槽越し・ガラス越しの撮影。**輪郭をぼかす**。
- 衣装：シアー素材、濡れた質感、装飾は最小限。肌の露出よりも**素材の透け方**で色気を出す。
- **EP のアートワーク全体のカラーパレット（深青・黒・銀）はこの曲基準で決めるのを推奨。**
