# M3｜「花言葉（仮）」／しっとり系バラード

> **枠：** 全体曲／しっとり系
> **仮タイトル候補：** 花言葉 ／ すき ／ 愛愛愛なんて
> **ポジション：** EP の芯。ライブでの弾き語り／照明を落とす一曲

---

## 1. ログライン

**「言えないままの言葉を、花の名前に預けて渡す。」**

叫ばない。爆発もさせない。
**7人が歌だけで立てる曲**を、この EP に1曲きっちり置きます。

## 2. コンセプト

本曲は EP の中で最も明確な**戦略的意図**を持った一曲です。

KENT の指摘を、そのまま企画の前提に置いています。

> 弾き語りのときにグッと、目と心を引き寄せられることが多いという感想を、
> あまり龍宮城の曲を知らないで見に来てくださった方からも、たくさんもらいました。
> （中略）もっと BPM が低い歌える曲がほしいなと思っています。（KENT）

> Spotify で人気な曲は、WALTZ、RONDO、BOYFRIEND、DEEP WAVE といった
> しっかりとした歌ものが聞かれている（KENT）

つまり本曲は、**ライブでの獲得力（初見の観客を掴む）とサブスクでの継続再生**という
2つの実績が既に確認されている領域に、意識的に投資する曲です。
EP の中で最も派手ではありませんが、**最も長く聴かれる可能性が高い**曲として設計します。

歌詞のモチーフは **「花言葉」**。
春空案の**「交わす」**——言葉を交わす、愛を交わす——を、
**「直接は言えないから、花に託して渡す」**という形で受けます。
ITARU 案の「真っ直ぐさ、朝日」は、曲の着地点（ラストで夜が明ける）として使います。

## 3. サウンド設計

| 項目 | 内容 |
|---|---|
| BPM | 66（ハーフバラード。ダブルで 132 に感じられる設計） |
| 拍子 | 4/4。※「WALTZ 系」を狙う場合は 3/4・BPM 84 の別案あり（後述） |
| キー | メジャー基調にマイナーの陰りを混ぜる（G / Em 行き来） |
| 尺 | 4:00〜4:30 |

### 音色設計

- **主役はピアノ。** イントロはピアノ1本。**ギターを足さない**（弾き語り転用のため輪郭を保つ）。
- **ストリングス。** 生ストリングス推奨。Ray 案の「壮大なオーケストラサウンド」をここで回収します。
  ただし**サビ1回目では入れない**。2番以降で段階的に増やす。
- **ドラムは 1:30 まで入れない。** 入った瞬間が曲最大の感情の変化点になります。
- **低域は最後まで薄く。** 音圧で押さず、声の余白で聴かせる。

### 展開イメージ

```
0:00  Intro    ピアノのみ。4小節
0:12  A1       ソロ1人目。囁くように。ほぼ無伴奏に近い
0:40  B1       2人目・3人目。ピアノにチェロが1本だけ加わる
1:00  Sabi 1   まだ小さい。ユニゾンではなくハモリ2声で
1:30  ── Drums in ── ここで初めてリズムが入る
1:32  A2       景色が変わる。ストリングス薄く
2:00  B2       徐々に厚く（KENT案：Aメロの静けさ→Bメロでヒートアップ）
2:20  Sabi 2   フルアンサンブル。全員
2:50  Bridge   **アカペラ／ハーモニーのみ。** 本曲の最大の見せ場
3:10  Last     転調 → 最も厚い一回 → 最後の1行だけピアノ1本に戻す
4:05  Outro    ピアノ。朝が来る
```

**設計意図：** 音を増やす方向で盛り上げるのではなく、
**「1:30 でドラムが入る」「2:50 で全部消える」**という2つの落差だけで感情を作ります。
最後の1行をピアノ1本に戻すのは、**弾き語りアレンジの予告**でもあります。

### 別案：WALTZ 系（3拍子・ダーク）

KENT が挙げた女王蜂「黒幕」「回春」路線を採る場合の派生案です。

- 3/4・BPM 84、マイナー固定、儚さと毒を混ぜる
- 「花言葉」のモチーフとの相性は非常に良い（花＝美しさと毒の両義性）
- 既存曲「WALTZ」との関係整理が必要 → **どちらを採るかは選曲時に判断**

## 5. 歌詞テーマ

**「花言葉」——言えない言葉の代理。**

- 具体的な花を**1種類だけ**決めて曲の背骨にする（曲名にも直結）。花言葉がそのままサビの一行になる形。
- 誰に向けた曲かを**明示しない**。恋人にも、家族にも、ファンにも、メンバー同士にも読める射程を保つ。
- 春空案「交わす」を軸に：**言葉を交わす／視線を交わす**。
  「交わせなかった」ことから書き始め、最後に「交わす」で終わる構造を推奨。
- 冨田案「サビに爆発するのではなく沸々と想いが込み上げる」を歌詞の温度設計に採用。
  **サビで叫ばない。** 一番強い言葉は、最後の1行にだけ置く。
- ITARU 案「朝日」は最終行に。夜通し言えなかった言葉が、朝になって渡される。
- **避けたい表現：** 大きな主語（「世界」「未来」「everybody」）。半径3メートルの具体で書く。

## 7. 歌割・ボーカル設計

**設計方針：本曲は歌割が作品の質を直接決めます。7人全員にソロを、ただし均等割りにはしない。**

| パート | 設計 |
|---|---|
| A1 冒頭 | **最も声に「素」が乗るメンバー**を1人目に。ここで曲の温度が決まる |
| A・B | ソロ回し。**1人あたり4小節以上**確保し、細切れにしない |
| サビ1 | ハモリ2声のみ（ユニゾンにしない）。上下の声質の相性で人選 |
| サビ2 | 全員ユニゾン＋ハモリ |
| ブリッジ（2:50） | **アカペラ。** 7人のハーモニー。ここが本曲の勝負どころ |
| ラスト 1行 | ソロ1名。**曲全体で最も重い1行**を任せる |

> **KENT の意見への対応：**
> 「個人個人のスキルやキャラクター、ソロなのかペアなのかユニゾンなのか、
> LIVE ではどうするのかまでちゃんと話し合って詰められたら全員も納得して臨める」
>
> 本曲については、**歌割会議に7人が同席する**ことを推奨します。
> 曲の性質上、技術の優劣より「その言葉を誰が言うと刺さるか」で決めるべきで、
> それは本人たちが最も判断材料を持っています。
> 4小節以上のソロを確保しているのは、この議論を成立させるための設計です。

- **キー設定は歌割確定後に最終決定。** 全員が地声で無理なく歌えるレンジを優先し、
  最高音は1名のソロ箇所にのみ置く。

## 8. ライブでの機能

- **本編中盤、照明を落とす一曲。** ダンスパートの後に置いて緩急を作る。
- **弾き語り／ピアノ1本アレンジを最初から用意する。**
  KENT の指摘どおり、初見の観客を掴んでいるのはこの形態です。
  音源制作の段階で**弾き語り用の譜面とキーも同時に作る**ことを推奨。
- 振付はつけない、または最小限（立ち位置と手の所作のみ）。
- アコースティック編成でのライブ／配信、ラジオ・音楽番組の1本勝負にも転用可能。

## 9. ビジュアル／MV

- **鍵となる画：** 夜明け前 → 朝日。花。7人が同じ場所にいるが、視線が交わらない。最後に交わる。
- 撮影は**ワンシチュエーション・長回し中心**。カット割りで感情を作らない。
- MV は必須ではないが、**パフォーマンス／弾き語り映像**の制作は強く推奨（低コストで再生が伸びる領域）。
- ジャケット／アートワークで花のモチーフを EP 全体の副次シンボルとして使える。
