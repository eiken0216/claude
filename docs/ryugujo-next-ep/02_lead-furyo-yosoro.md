# M2｜リード②「不良（仮）」／「ヨーソロー」

> **枠：** リード曲／不良・海賊ヨーソロー
> **仮タイトル候補：** 不良 ／ ヨーソロー ／ 蜃気楼
> **ポジション：** ライブアンセム。EP 中盤・ライブ本編の起爆剤

---

## 1. ログライン

**「ならず者の船が、夜の海へ出る。ヨーソロー。」**

行儀よくやってきた者たちの歌ではなく、**枠から外れた7人が船を出す**歌。
「ヨーソロー（宜候）」＝このまま直進せよ、という号令をフックに、
会場全員が同じ声を出す曲を作ります。

## 2. コンセプト

龍宮城という名前が持つ**海の物語**を、初めて正面から曲にする一曲。
ただし竜宮城の絢爛ではなく、**そこへ向かう荒れた航海**のほうを描きます。

- **「不良」**＝ 型から外れた者。優等生ではない7人の自己申告。
- **「海賊」**＝ 群れ。仲間。旗。略奪ではなく**自分たちの居場所を取りに行く**姿。
- **「ヨーソロー」**＝ 号令。この一語をコール&レスポンスの核に据えます。

冨田案の「ニュージーランドのハカのような漢らしさ」「絶望や最底辺から這い上がる小さな蒼い灯火」を、
**出航の号令**として翻訳したのが本曲です。
また ITARU 案の「サーカスのような遊びと狂気」は、**祝祭としての狂騒**という形でここに回収します。

メモにあった **「蜃気楼／ギターリフもの／挑戦」** も本曲で実現します。
龍宮城がこれまで主戦場にしてこなかった**ギターリフ主導の曲**という挑戦枠として、
歌う前にリフだけで曲が判別できる状態を目指します。

## 3. サウンド設計

| 項目 | 内容 |
|---|---|
| BPM | 138（ハーフで 69 に落とせる設計） |
| 拍子 | 4/4 主体。B メロのみ 6/8 に振って船の揺れを出す |
| キー | マイナー（Em / Am 想定）。ラストで半音上げ転調 |
| 尺 | 3:20〜3:40（ライブ想定でコンパクトに） |

### 音色設計

- **主役：ギターリフ。** 歪んだ単音リフ。イントロ4小節で覚えられる、**歌えるリフ**であること。
- **土台：生ドラム＋和太鼓／木製パーカッション。** 冨田案の Heilung「In Maidjan」を参照し、
  鹿皮系太鼓・骨や木を打ち鳴らす音・ラトルを**実音でレイヤー**。打ち込みだけにしない。
- **色付け：ホーン（ホルン／トロンボーン）。** 号令感と航海のファンファーレ。
- **足踏み＋手拍子＋ガヤ。** レコーディングでメンバー7人＋スタッフで実際に録る。
  ライブでの一体感の設計図をそのまま音源に入れておく。

### 展開イメージ

```
0:00  Intro    ギターリフ単騎 4小節 → 足踏みが乗る → 太鼓の一撃
0:14  A Verse  低く抑えた語り口。ソロ回し。まだ船は港にいる
0:38  B        6/8 に転換。船が揺れ出す。徐々にヒートアップ
0:52  Hook     「ヨーソロー！」全員ユニゾン＋コール&レスポンス
1:16  A2       同じリフの上でメロが変化。ガヤが増える
1:40  B2 → Hook
2:10  Bridge   全楽器ストップ → 太鼓と声だけ（ハカ的な地声の斉唱）
2:28  Break    リフ復活。最も熱いソロ4小節
2:40  Last Hook 半音上げ転調 → フル。手拍子で終わる
```

**設計意図：** 2:10 のブリッジが本曲の心臓部。
**楽器を全部止めて、生の声と太鼓だけにする。** ここが冨田案の「ハカ」の直訳であり、
アリーナで最も画になる20秒になります。

## 5. 歌詞テーマ

**「はみ出したまま、行く。」**

- 一人称は **「僕ら」固定**。個ではなく群れの歌。
- 「不良」を**責められる属性ではなく、選び取った生き方**として書く。
- 航海のメタファーを通す：舵／旗／灯火／潮／夜明け前。
  - 冨田案の**「小さな蒼い灯火」**をサビの決めワードに据えるのを推奨。
- **「ヨーソロー」は絶対に説明しない。** 意味を歌詞で解説せず、号令として置く。
  聴き手が意味を調べたくなる状態を作るほうが強い。
- 春空案「交わす」は、ここでは**「盃を交わす」＝仲間との誓い**として1フレーズ差し込む。
- **避けたい表現：** 誰かを見下す種類の反抗。敵は外ではなく状況、という書き方に留める。

| 対抗 | monjoe | 和の要素と歌の強度 |

**発注時の必須伝達事項**

1. **ギターリフが主役。** イントロ4小節で覚えられる単音リフを最優先で作ってほしい
2. 「ヨーソロー」を**ハンドクラップ／コール可能なフック**に
3. パーカッションは打ち込みでなく生音レイヤー前提（Heilung 参照）
4. 2:10 のブリッジは**楽器全停止・声と太鼓のみ**を確保
5. ライブ想定で尺は 3:40 以内

## 7. 歌割・ボーカル設計

**設計方針：全員もの。ユニゾンと掛け合いを主軸に、7人が「群れ」に聞こえること。**

| パート | 設計 |
|---|---|
| A メロ | ソロ回し（2小節ずつ）。**低音・太い声質のメンバーから**始めて船底の重さを出す |
| B メロ | ペア／トリオの掛け合い。声の相性でペアを組む（似た声＝厚み／対照的な声＝立体感） |
| フック | **全員ユニゾン。** ここは誰か1人を立てない。7人が1つの塊に聞こえることを優先 |
| ブリッジ（2:10） | **地声の斉唱。** 歌唱力の順位ではなく、7人の声の総量で押す |
| ラスト前ソロ4小節 | 最も熱量で押せるメンバー1名。本曲唯一の「1人が立つ」瞬間 |
| ラップ | **1名・8小節まで。** 歌の中のアクセントとして配置し、主役にはしない |

> **KENT の意見への対応：**
> 「ラップがメインになるとラップの良さも龍宮城の良さも消える／歌の中のラップならバリエーションとして良い」
> という指摘をそのまま設計に反映し、本曲のラップは**8小節・1名まで**と上限を設定しています。
> ゴリゴリの HIPHOP は M5 に集約する方針です。

## 8. ライブでの機能

- **本編中盤の起爆剤。** または本編ラスト前の総立ちポイント。
- **コール&レスポンスの設計を音源制作と同時に行う**（後付けにしない）。
  - 「ヨーソロー！」のレスポンス位置を音源のガヤで先に提示しておく。
- 足踏み・手拍子で客席を巻き込む。振付は**難度を上げすぎない**（客席が真似できることを優先）。
- ブリッジの太鼓＋斉唱は、**メンバー自身が太鼓を叩く**演出を推奨（冨田案の実装）。

## 9. ビジュアル／MV

- **鍵となる画：** 夜の海、船、旗、松明。荒れた甲板の上の7人。
- 冨田案の「戦争後のような荒れ果てた灰色の世界」をロケーションのトーンに採用。
  色を抜いた画面の中で、**炎（蒼い灯火）だけが色を持つ**。
- 衣装：海賊・ならず者。ただしコスプレに寄せすぎず、**現代の服の中に記号を1点だけ**入れる。
- 泥・水・煙を使った実写演出。CG に寄せない。
